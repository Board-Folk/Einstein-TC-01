# Einstein TC01 Tandy Joystick Adapter

![Built TC01 Tandy joystick adapter board v1 in Green](https://github.com/Board-Folk/Einstein-TC-01/blob/main/images/TC01TandyJoystickv1_Small.png)

Simple adapter for Tandy (Coco) and compatible analogue joysticks. Tested with Tandy Deluxe Joystick 26-3012B.

Just 2 DIN sockets, 7 pin DIN and 6 pin DIN. 7 pin DIN uses the same multi-format footprint as the main board replica.
